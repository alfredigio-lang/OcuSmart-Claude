Use the `ocusmart` skill and read `references/evidence-research.md` (TrueRef section). Verify the references below with real retrieval (WebSearch / WebFetch on PubMed, Crossref, DOI resolvers, publisher pages), sending only bibliographic metadata, never manuscript passages or case data. Report status per reference, flags separately, the consulted source and access date. If retrieval fails, say "external verification not performed" rather than inferring fabrication.
